### Digit recognization using only numpy and pygame 
**Mnist dataset from [Kaggle](https://www.kaggle.com/code/heeraldedhia/mnist-classifier-first-deep-learning-project/input?select=sample_submission.csv)**

Pretrained weights and bias are stored in `weights.npy` and `bias.npy`.
If you want to train from scratch please empty these two files by using method in **DeepNeuralNetwork** class or just clear by yourself.

### Evaluate 
- **Train Accuracy** : `0.99`, **Train Loss** : `0.90`
- **Test Accuracy** : `0.97`, **Test Loss** : `0.79`
